# AI on Trial

AI on Trial is an interactive physical computing project that explores bias and automated decision-making in AI-driven recruitment.

The project uses physical interaction, sensors, visual feedback, and deliberately arbitrary assessment criteria to encourage participants to question how automated systems evaluate human behaviour.
